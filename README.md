# SaveBox 📦

**Save now. Find it later.**

SaveBox is a simple, local-first mobile application built with React Native and Expo to help users save and organize notes and links they want to revisit later.

## ✨ Features

- **Save notes:** Store a title and content for useful information.
- **Save links:** Keep useful URLs together in one place.
- **Edit and delete:** Update or remove saved items whenever needed.
- **Search:** Find saved content by title, text, or URL.
- **Tags:** Organize items using custom tags.
- **Archive and restore:** Separate active items from archived ones.
- **Image selection:** Attach an image to an item.
- **Local persistence:** Keep saved items on the device using AsyncStorage.
- **Open links:** Launch saved URLs in the browser.

## 🛠️ Tech Stack

- React Native
- Expo
- JavaScript
- AsyncStorage
- Expo Image Picker

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Expo Go on a compatible mobile device
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kabeer180/SaveBox.git
   ```

2. Open the project folder:

   ```bash
   cd SaveBox
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the Expo development server:

   ```bash
   npx expo start
   ```

5. Scan the QR code using Expo Go to run the app on your phone.

## 📱 Project Scope

SaveBox is currently a local-first application. Saved items are stored on the device; cloud synchronization and user authentication are not included in this version.
